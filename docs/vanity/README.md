# Import host

The package directory and Go discovery service are maintained in
[`toshicloud/go.toshicloud.io`](https://github.com/toshicloud/go.toshicloud.io)
and deployed at [go.toshicloud.io](https://go.toshicloud.io/).

That repository contains the Worker, package entries and deployment
configuration. Cubby's Go module path remains `go.toshicloud.io/cubby`.
